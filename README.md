# 🛡️ TruthLens AI — Fake News & Deepfake Detection Platform

> **"Verify Before You Trust."**  
> An autonomous, multi-modal **Explainable Artificial Intelligence (XAI)** platform designed to detect and dissect digital disinformation, fake news articles, and synthetic deepfake media.

---

## 🚀 Live Demo & Quickstart

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build
```

Open your browser at **`http://localhost:5173/`** or **`http://localhost:5174/`**.

## 🌟 Key Features

- **Multi-Modal Detection**: Supports **Text Articles**, **Synthetic Images**, and **Deepfake Videos**.
- **Explainable AI (XAI)**:
  - Interactive sentence-level token salience map (Clickbait, Unsupported claims, Conspiracy framing, Verified facts).
  - Visual Artifact Map overlays & Discrete Cosine Transform / FFT Frequency domain analysis.
- **Calibrated Confidence Gauge**: Bayesian probability meter with risk assessment and safety recommendations.
- **4-Tier Forensic Evidence Grid**: Source Credibility, Fact-Check cross-references (Reuters, Snopes, GFCN), Reverse Duplication timestamping, and EXIF Sensor PRNU inspection.
- **One-Click PDF Audit Export**: Generates tamper-evident forensic certificates.
- **Admin Command Center**: Recharts 7-Day threat volume area charts, media distribution pie charts, model cluster telemetry, and active learning synchronization.
- **Searchable History & Archive**: Search, filter, and export historical audits with LocalStorage persistence.
